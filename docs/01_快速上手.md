# 快速上手

> 适用于 InsightClass `1.2.x`。

## 1. 选择使用方式

### Windows 便携版

从 [GitHub Releases](https://github.com/ygttygtt/InsightClass/releases/latest) 下载
`InsightClass-Web.zip`，完整解压后运行 `InsightClass.exe`。

- 需要 Windows 10/11 和 Microsoft Edge WebView2 Runtime。
- 首屏会先显示服务/模型加载状态，无需等待黑框窗口。
- 关闭主窗口后应用留在系统托盘；从托盘退出才会结束后端。
- 发行版为 onedir 目录模式；可为 EXE 创建桌面快捷方式，但不能只复制 EXE。
- 左上角按钮可切换深色/浅色主题，选择会在后续启动中保留。
- 第一次使用 RTSP 前，需要在设置中填写真实凭据。

### 从源码运行

需要 Python 3.10+、Node.js LTS 和 npm：

```powershell
git clone https://github.com/ygttygtt/InsightClass.git
Set-Location InsightClass

python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -e ".[web]"

Push-Location frontend
npm ci
npm run build
Pop-Location

insightclass serve --host 127.0.0.1 --port 8000
```

浏览器打开 `http://127.0.0.1:8000`。端口冲突时可改用 `--port 8080`。

## 2. 完成第一次检测

### 图片

1. 选择“图片检测”。
2. 上传 JPG、JPEG、PNG、BMP 或 WebP。
3. 点击开始检测，查看标注图、类别统计和延迟。

单张图片最大 25 MiB，解码后不超过 5000 万像素。

### 视频

1. 选择“视频检测”。
2. 上传 MP4、AVI、MOV、MKV、M4V 或 WebM。
3. 开始分析，完成后播放视频并查看与当前帧同步的检测框。

单个视频最大 2 GiB。长视频会逐帧推理，请根据 CPU 性能预留处理时间。

### 电脑摄像头

1. 选择“电脑摄像头”并点击开始。
2. 允许浏览器访问摄像头。
3. 停止或切换检测源时，应用会释放摄像头设备。

非 localhost 的浏览器页面通常要求 HTTPS。局域网测试可用：

```powershell
insightclass serve --host 0.0.0.0 --port 8000 --https
```

### RTSP 摄像头

1. 打开设置，填写共享 RTSP 用户名、密码和端口。
2. 添加摄像头 IP/名称，或导入 CSV。
3. 先测试连通性，再选择摄像头并开始检测。

系统优先连接 Channel 101；检测到持续黑帧时会尝试 Channel 102。密码留空保存会
保留已有密码，设置读取接口不会返回明文。

## 3. 监控台与大模型

监控大屏展示摄像头在线状态、四类行为累计计数、摄像头对比和 24 小时趋势。
这些统计保存在当前进程内，后端退出后会重置。

启用 AI 分析：

1. 在设置中填写 OpenAI 兼容 Base URL、模型名、API Key 和超时。
2. 点击“测试连接”。
3. 进入监控大屏，点击“AI 分析”。

分析只接收统计 JSON，不会上传原始视频帧。未配置模型时，AI 分析会返回明确的
配置错误，不影响视觉检测功能。

## 4. 数据与训练闭环

训练功能需要额外依赖：

```powershell
python -m pip install -e ".[ultralytics,web]"
python scripts/test_environment.py
```

### 创建数据集清单

```powershell
insightclass create-manifest `
  --config configs/dataset_manifest.example.yaml `
  --output data/processed/classroom_behavior_v1/manifest.yaml
```

先按视频划分 train/val/test，再进行抽帧：

```powershell
insightclass extract-frames `
  --manifest data/processed/classroom_behavior_v1/manifest.yaml `
  --fps 1.0 `
  --max-frames-per-video 300 `
  --target-width 960
```

标注完成后检查 YOLO 标签并生成训练配置：

```powershell
insightclass inspect-yolo `
  --dataset-root data/processed/classroom_behavior_v1 `
  --class-config configs/classes.yaml `
  --output reports/dataset_inspection.json

insightclass write-yolo-yaml `
  --dataset-root data/processed/classroom_behavior_v1 `
  --class-config configs/classes.yaml `
  --output data/processed/classroom_behavior_v1/yolo_dataset.yaml
```

### 训练、验证和推理

```powershell
insightclass train --config configs/training.ultralytics.example.yaml
insightclass validate --config configs/training.ultralytics.example.yaml
insightclass predict --config configs/inference.ultralytics.example.yaml

insightclass compare-experiments `
  --experiments-root experiments `
  --output reports/experiment_summary.csv
```

`data/processed/`、`experiments/` 和 `reports/` 默认不进入 Git。模型、数据和代码的
版本对应关系应记录在实验产物中。
