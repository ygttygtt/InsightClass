# 09 - 打包与发行

## 1. 发行形态

InsightClass 的 Windows 发行版将以下部分打包到同一个便携目录：

- FastAPI 后端、ONNX Runtime 推理引擎和内置 ONNX 模型
- React 生产构建产物
- pywebview 独立窗口和系统托盘

构建会生成：

- `dist/InsightClass-Web/`：解压后可直接运行的目录
- `dist/InsightClass-Web/InsightClass.exe`：无控制台窗口的启动程序
- `InsightClass-Web.zip`：用于分发的便携版压缩包

当前流程不生成安装程序。正式发布安装包或代码签名应在便携版验证通过后，
作为独立发行步骤处理。

## 2. 环境要求

构建机需要：

- Windows 10/11
- Python 3.10 或更高版本
- Node.js 和 npm（建议使用当前 LTS）
- 可访问 Python 和 npm 包源

运行打包后的应用不需要 Python 或 Node.js，但需要 Microsoft Edge WebView2
Runtime。Windows 10/11 通常已预装；精简系统需要单独安装 WebView2 Runtime。

## 3. 一键构建

在项目根目录运行：

```powershell
# 安装 Python 依赖、构建前端、打包并压缩
.\scripts\build_package.ps1

# 当前 Python 环境已安装 .[web] 和 PyInstaller 时
.\scripts\build_package.ps1 -SkipDeps

# 指定 Python 解释器
.\scripts\build_package.ps1 -Python "C:\path\to\python.exe"
```

脚本会依次：

1. 检查 spec、模型、前端锁文件等必要输入。
2. 使用当前 Python 环境安装 `.[web]` 和 PyInstaller（除非传入 `-SkipDeps`）。
3. 使用 `npm ci` 和 `npm run build` 生成 React 生产文件。
4. 通过 `InsightClass.spec` 创建 `console=False` 的 onedir 应用。
5. 初始化运行时配置目录和实验目录，并生成 `InsightClass-Web.zip`。

每次构建都会重新生成 `dist/InsightClass-Web/` 和根目录下的 ZIP。不要在发行
目录内保存唯一副本的数据。

## 4. 启动与托盘行为

双击 `InsightClass.exe` 后，桌面窗口会立即显示启动页。FastAPI 服务和模型在
后台初始化；服务就绪后，窗口自动切换到完整前端。前端控制台会继续展示模型
的 `loading`、`ready` 或 `error` 状态。

- 应用只监听 `127.0.0.1`，默认优先使用端口 8000；占用时自动选择其他端口。
- 关闭窗口会隐藏到系统托盘，后端和摄像头服务保持运行。
- 双击托盘图标或选择“打开 InsightClass”可恢复窗口。
- 再次运行 `InsightClass.exe` 会唤醒已有实例，不会启动第二套后端。
- 选择托盘菜单中的“退出”才会关闭后端并结束进程。

启动器会在 `configs/.port` 和 `configs/.control` 中记录当前实例的本地端口，
正常退出时自动清理。这两个文件不需要手动配置。

## 5. 运行时文件

便携目录中需要保留以下结构：

```text
InsightClass-Web/
|-- InsightClass.exe
|-- _internal/          # Python、前端、模型和原生运行库
|-- configs/
|   |-- classes.yaml    # 内置行为类别
|   |-- app.yaml        # 模型、RTSP 和大模型设置
|   `-- cameras.yaml    # 摄像头列表
`-- experiments/        # 用户实验数据
```

`configs/app.yaml`、`configs/cameras.yaml` 和 `experiments/` 位于 EXE 旁边，升级
覆盖前应备份。`_internal/` 是程序资源，不能删除或只复制 EXE 单独运行。

## 6. OpenAI 兼容大模型

在应用“设置”页面填写：

- Base URL，例如 `https://api.openai.com/v1` 或兼容服务的 `/v1` 地址
- 模型名称
- API Key（本地免鉴权服务可留空）
- 请求超时

保存后可直接测试连接。API Key 写入本机 `configs/app.yaml`，读取设置时只返回
掩码，不会把明文密钥发回前端。也可以在启动前设置环境变量覆盖本地配置：

```powershell
$env:OPENAI_BASE_URL = "https://api.openai.com/v1"
$env:OPENAI_MODEL = "your-model"
$env:OPENAI_API_KEY = "your-api-key"
.\InsightClass.exe
```

兼容服务需要实现 `POST /chat/completions` 的 OpenAI 格式响应。

## 7. 发布前验证

源代码质量检查：

```powershell
python -m pytest -q
ruff check src tests
Push-Location frontend
npm ci --no-audit --no-fund
npm run build
Pop-Location
```

便携版冒烟检查：

1. 在不含 Python 环境配置的新目录解压 ZIP。
2. 双击 EXE，确认没有控制台黑框，窗口先显示加载页再进入应用。
3. 确认控制台能看到模型状态，并完成一张图片的检测。
4. 测试浏览器摄像头和至少一台 RTSP 摄像头的连接、停止与重连。
5. 关闭窗口后确认托盘仍在，再次启动 EXE 能恢复原窗口。
6. 从托盘退出，确认进程结束且本地服务不再监听端口。

## 8. 常见问题

### 窗口空白或提示缺少 WebView2

安装 Microsoft Edge WebView2 Runtime 后重新启动应用。企业精简镜像应将
WebView2 Runtime 纳入系统部署基线。

### 构建时文件被占用

先从系统托盘退出正在运行的 InsightClass，再重新执行打包脚本。不要在应用
运行期间覆盖 `dist/InsightClass-Web/`。

### 默认端口被占用

桌面版会自动换用空闲端口，无需手工处理。使用 CLI 启动服务时，可显式指定：

```powershell
insightclass serve --host 127.0.0.1 --port 8080
```

### 杀毒软件误报

PyInstaller 生成的未签名程序可能触发启发式检测。正式分发应使用可信证书对
EXE 签名并通过发布渠道提供校验值，不建议让最终用户长期关闭安全软件。

### 包体大小

ONNX Runtime、OpenCV、WebView 桥接和模型会占据主要空间。当前 spec 已排除
PyTorch、Ultralytics、Qt、CEF、Jupyter、Sphinx 和 tkinter 等非运行时依赖；
不要使用通用 `webview.platforms` 隐式导入，否则可能重新带入多套 GUI 后端。
