# 四类课堂行为标注规范

> 标签顺序以 `configs/classes.yaml` 为准。本规范用于目标检测框，不用于身份识别
> 或纪律结论。

## 1. 类别定义

| class_id | 训练类 ID | 中文 | 最低视觉证据 |
|---:|---|---|---|
| 0 | `phone_use` | 玩手机 | 手机、手部操作和注视关系至少有两项清晰可见 |
| 1 | `talking` | 交谈 | 面向交流对象，并有口型、互动或连续帧上下文支持 |
| 2 | `sleeping` | 打瞌睡 | 趴桌、持续闭眼或稳定困倦姿态，而非瞬时低头 |
| 3 | `standing` | 站立 | 学生躯干明显直立并离开正常坐姿 |

正常听课、写字和无法确定的模糊样本不标行为框，可作为负样本或难例单独管理。

## 2. 各类别边界

### `phone_use`

正例：手机可见且学生正在手持、查看或操作；手机部分遮挡但手眼关系明确。

反例：低头写字、看书、拿计算器或文具；桌面有疑似手机但没有使用证据。

模糊例：只看到反光边角或单纯低头。证据不足时不标，并加入难例清单。

### `talking`

正例：两名或多名学生明显相向交流；回头交流且口型/互动在相邻帧持续出现。

反例：看老师、看黑板、短暂转头、打哈欠、咳嗽或独自朗读。

模糊例：只有头部方向变化。至少需要一个额外视觉证据再标注。

### `sleeping`

正例：趴桌；持续闭眼；头部明显下垂且姿态稳定。

反例：低头写字、看书、弯腰捡物或瞬间眨眼。

模糊例：单帧看似闭眼但缺乏姿态证据。可查看相邻帧，不得凭主观猜测。

### `standing`

正例：学生从座位起立、直立回答或站立移动，躯干与坐姿有明确区别。

反例：坐姿伸懒腰、半蹲捡物、老师在讲台站立、画面边缘仅露出上半身。

模糊例：座椅遮挡下半身且无法判断是否离座。需要结合躯干高度、桌椅关系和相邻
帧确认。

## 3. 框选规则

- 使用“行为主体框”，优先覆盖学生上半身；`standing` 可根据画面覆盖完整可见身体。
- `phone_use` 框尽量同时包含头、手和手机，不单独框手机。
- 框应贴合主体，不大面积包含邻座，也不能只框头部造成语义丢失。
- 被遮挡但主体与行为仍明确时可标；行为归属无法确定时不标。
- 每个可区分的行为主体单独画框。

## 4. 同一学生多行为

当前检测任务为单标签框。同一帧同一学生只保留一个最有证据、最能解释主体状态
的主行为。建议冲突优先级：

1. `phone_use`
2. `sleeping`
3. `talking`
4. `standing`

例如站立使用手机优先标 `phone_use`；站立回答且无其他目标行为标 `standing`。
若多标签场景成为核心需求，应新建数据版本和任务定义，不得在现有数据中临时混用。

## 5. 负样本与排除项

- 有学生但没有四类行为的图片是有效负样本。
- 空教室、严重模糊、全黑或损坏图片应排除，不作为负样本充数。
- 同一视频大量相邻无事件帧应降采样，避免负样本占比失衡。
- 教师、工作人员和屏幕中的人物不按学生行为标注。

## 6. 质量控制

- 标注前用 50 至 100 张校准集统一口径。
- 每轮至少随机复核 5%，低频类、后排小目标和遮挡样本提高到 10% 以上。
- 统计每类图片数、框数、空标签数和框面积分布，调查异常峰值。
- 使用 `insightclass inspect-yolo` 检查越界、未知类别、坏格式和过小框。
- 维护难例清单，记录路径、争议点、结论、审核人和日期。
- train/val/test 必须按视频级隔离，不能靠移动单张图片重新平衡。

## 7. 版本冻结

每个可复现实验应保留：

- 数据集版本和 Manifest
- `configs/classes.yaml` 快照
- 标注工具及模型版本
- 质检报告和人工抽查记录
- 修订规则与受影响样本列表

类别新增、顺序变化或冲突规则变化都需要新数据版本和重新训练。
